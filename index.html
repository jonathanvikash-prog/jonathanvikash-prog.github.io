01

Automated Vegetable Quality Grading & Sorting Machine

A machine-vision-based automated sorting system developed to identify and sort two types of vegetables — carrots and brinjals — based on their visual characteristics.

Project Focus

The system combines computer vision, embedded control, sensors, motors and mechanical sorting mechanisms to automate vegetable handling with minimal human intervention.

Key Engineering Features

  • YOLO-based computer vision for vegetable detection and classification
  • Rotary wheel dispenser for controlled vegetable feeding
  • Conveyor-based transportation and sorting mechanism
  • ESP32-based distributed control system
  • Photoelectric sensor synchronization between detection and sorting
  • Servo-controlled mechanical sorting gates
  • Real-time hardware and software integration

04

Smart Street Light System

An embedded automation system designed to reduce unnecessary energy consumption by automatically adjusting street-light intensity according to ambient light and motion.

Project Focus

The system combines ambient-light sensing with motion detection to keep lights at low brightness during normal conditions and increase illumination when movement is detected.

Key Engineering Features

  • PIC16F877A microcontroller-based control
  • LDR-based ambient light detection
  • Two IR proximity sensors for motion detection
  • PWM-based LED brightness control
  • Low-power 10% illumination during low-light conditions
  • Automatic increase to 100% brightness when motion is detected
  • Fully assembled and soldered on dot board for physical hardware implementation

PIC16F877A · Embedded C · mikroC PRO · Proteus · PICkit3 · PWM · LDR · IR Sensors
